# VoiceTyperPro-Updates# Voice Typer Pro 3

تایپ با صدا به فارسی و انگلیسی در همه‌ی برنامه‌های ویندوز. مکان‌نما را هر جا بگذارید، میانبر را بزنید و صحبت کنید؛ متن همان‌جا نوشته می‌شود.

## دوره‌ی آزمایشی، نسخه‌ی رایگان و لایسنس
- ۴۸ ساعت اول همه‌ی امکانات باز است. این دوره به کامپیوتر گره خورده و با پاک کردن و نصب دوباره از نو شروع نمی‌شود.
- بعد از آن فقط دیکته‌ی معمولی (متن بعد از توقف ضبط تایپ می‌شود) رایگان است. تایپ زنده، موتورهای هوش مصنوعی، ویرایش هوشمند، ترجمه، خواندن متن، ویرایش با صدا، پروفایل برنامه‌ها، واژه‌نامه‌ی شخصی، فرمان‌های صوتی، نشانه‌گذاری گفتاری و تاریخچه با لایسنس باز می‌شوند (**تنظیمات ← لایسنس**).
- مدت دوره‌ی آزمایشی، امکانات رایگان و لایسنس‌ها از پنل مدیریت تعیین می‌شوند؛ سرور و پنل در `server/` هستند و راهنمایشان در `server/SETUP-fa.md`.

## بدون کلید API چه کار می‌کند؟ (با لایسنس یا در دوره‌ی آزمایشی)
- دیکته‌ی فارسی و انگلیسی با موتور «استاندارد» (رایگان)، در حالت فشردن یا نگه‌داشتن، با مکث (Shift یا دکمه‌ی کپسول)، توقف خودکار پس از سکوت و تایپ زنده.
- تایپ زنده با موتور «استاندارد» کلمه‌به‌کلمه است: هر کلمه کمتر از یک ثانیه بعد از گفتن تایپ می‌شود و هر جمله با مکث شما، با علامت مناسب بسته می‌شود. با موتورهای دیگر، یا اگر این سرویس در دسترس نباشد، جمله‌به‌جمله انجام می‌شود.
- اصلاحات محلی: حذف «امم» و تپق و کلمات تکراری (در سبک «تمیز و دقیق»)، نشانه‌گذاری گفتاری و هوشمند، عددها، ارقام فارسی، فرمان‌های صوتی، واژه‌نامه‌ی شخصی و متن‌های آماده.
- هشدار زبان اشتباه: اگر به زبانی غیر از زبان گفتار صحبت کنید، به‌جای تایپ کلمات نامفهوم خبرتان می‌کند.
- خواندن متن انتخاب‌شده با صدای طبیعی (Microsoft Edge) — رایگان و بدون کلید.
- تاریخچه، پخش و ارسال دوباره‌ی صدا، ویرایشگر سریع، آمار، پروفایل هر برنامه، به‌روزرسانی خودکار.
- متن هیچ‌وقت گم نمی‌شود: هر جا امکان تایپ باشد متن همان‌جا تایپ می‌شود و اگر نباشد (دسکتاپ، عکس، صفحه‌ی وب بدون کادر متن و…) یا برنامه متن را نگیرد، ویرایشگر سریع خودکار باز می‌شود. با گزینه‌ی «همیشه در ویرایشگر باز شود» (صفحه‌ی دیکته یا منوی کنار ساعت) متن همیشه اول در ویرایشگر نمایش داده می‌شود.

## با کلید API چه چیزی اضافه می‌شود؟
- موتورهای «سریع» (Groq)، «دقیق» (OpenAI) و «هوشمند» (Gemini) برای تشخیص گفتار.
- ویرایش هوشمند متن و سبک‌های نوشتن: رسمی (کتابی)، صمیمی (محاوره‌ای)، ایمیل، فهرست نکات، و «تمیز و دقیق» کامل.
- ترجمه: ترجمه‌ی همزمان هنگام دیکته، ترجمه‌ی متن انتخاب‌شده و فرمان «… به انگلیسی ترجمه کن».
- **ترجمه بدون کلید اصلاً اجرا نمی‌شود** (هیچ درخواستی ارسال نمی‌شود) و فقط پیام «افزودن کلید» نمایش داده می‌شود.

سرویس‌های پشتیبانی‌شده: Groq، Google Gemini، OpenAI و OpenRouter؛ برای هر سرویس تا سه کلید (کلید پشتیبان هنگام تمام شدن سهمیه).

## جایگزینی خودکار (Fallback)
- **گفتار:** موتور انتخابی اول امتحان می‌شود؛ اگر «جایگزینی خودکار» روشن باشد، سپس موتورهای دارای کلید و در نهایت موتور رایگان. کلید نامعتبر یک ساعت کنار گذاشته می‌شود و خطای سهمیه تکرار بی‌پایان ندارد.
- **متن:** «خودکار» یعنی اولین سرویس دارای کلید و در صورت خطا سرویس بعدی؛ انتخاب یک سرویس خاص یعنی اول همان، و بقیه فقط در صورت خطا.
- مدل‌ها مستقیم از سرویس فهرست می‌شوند؛ اگر مدلی بازنشسته شود، یک بار با مدل معتبر جایگزین و ذخیره می‌شود.

## نصب از کد منبع
`run.bat` را اجرا کنید (Python 3.11 تا 3.14). یک محیط `.venv` ساخته، وابستگی‌ها نصب و برنامه اجرا می‌شود.
برنامه همراه یک پنجره‌ی cmd باز می‌شود که گزارش را لحظه‌به‌لحظه نشان می‌دهد. بستن این پنجره برنامه را هم می‌بندد. برای گزارش مشکل، خطوط مربوط را از همین پنجره کپی کنید. همین گزارش در `%APPDATA%\VoiceTyperPro\voice_typer.log` هم ذخیره می‌شود و متن دیکته و کلیدها هرگز در آن ثبت نمی‌شوند.
داده‌های کاربر در `%APPDATA%\VoiceTyperPro` نگه داشته می‌شوند و با به‌روزرسانی دست نمی‌خورند.

## به‌روزرسانی از نسخه‌ی ۲ (درجا)
این نسخه با همان کانال به‌روزرسانی نسخه‌ی ۲ منتشر می‌شود (`ElandraLabs/VoiceTyperPro-Updates`، آخرین Release با فایل ZIP). وقتی کاربر نسخه‌ی ۲ آن را نصب کند:
- فایل‌ها روی همان پوشه کپی می‌شوند و برنامه با `main.py` (یا `VoiceTyperPro.exe`) دوباره اجرا می‌شود.
- در اولین اجرا تنظیمات (`config.json`)، واژه‌نامه، تاریخچه، آمار و کلیدها (Credential Manager و فایل‌های رمزشده‌ی `.secure_*`) منتقل می‌شوند. انتقال کلیدها فقط یک بار انجام می‌شود.
- به‌روزرسان نسخه‌ی ۲ بسته‌ی پایتون نصب نمی‌کند؛ نسخه‌ی ۳ بسته‌های جاافتاده را خودش در پس‌زمینه نصب می‌کند و پس از پایان، اجرای دوباره را پیشنهاد می‌دهد.

**ساختار ZIP انتشار:** یک پوشه‌ی بالایی که `main.py` (نسخه‌ی کد منبع) یا `VoiceTyperPro.exe` (نسخه‌ی ساخته‌شده) مستقیم داخل آن باشد.

## ساخت نسخه‌ی اجرایی با PyInstaller
- حالت **onedir** (نه onefile) و نام فایل اجرایی دقیقاً **`VoiceTyperPro.exe`** — به‌روزرسان نسخه‌ی ۲ همین نام را می‌بندد و دوباره اجرا می‌کند.
- `--collect-data speech_recognition` (فایل‌های flac موتور رایگان)، `--collect-submodules comtypes` (تشخیص جای تایپ)، پوشه‌ی `assets` (قلم Vazirmatn) و `--noconsole`.
- در ZIP انتشار، `VoiceTyperPro.exe` و پوشه‌ی `_internal` را مستقیم داخل یک پوشه‌ی بالایی قرار دهید.
- رابط کاربری با PySide6 (مجوز LGPL) ساخته شده است: فایل `THIRD-PARTY-NOTICES.txt` (مجوز همه‌ی اجزای متن‌باز) کنار `VoiceTyperPro.exe` قرار می‌گیرد و `edge_tts` (LGPL) به‌صورت فایل‌های `.py` جمع‌آوری می‌شود (`module_collection_mode`) تا قابل جایگزینی باشد.

**English summary.** Persian/English voice typing for every Windows app. Every feature is open for a 48-hour trial (tied to the computer, so reinstalling does not restart it); after that standard dictation stays free and the rest needs a license (Settings → License), with the rules set in the owner's panel (`server/`, see `server/SETUP-fa.md`). Without an API key it offers dictation, live typing that streams word by word, local clean-up, a wrong-language warning and read-aloud; a key adds more engines, smart editing with writing styles, and translation — translation never runs without a key. Text is typed wherever typing is possible; when a spot takes no text (every paste is confirmed), or always if the user prefers, it opens in the quick editor so nothing is lost. Updates in place over version 2 through the same release channel; user data lives in `%APPDATA%\VoiceTyperPro`. For PyInstaller use onedir with the executable named `VoiceTyperPro.exe`.
